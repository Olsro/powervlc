# Security Policy

## Security advices
- Use always the latest available version of PowerVLC
- Load only files and network streams from trusted sources
- You are probably going to load PowerVLC inside an environment that is lacking years of security updates. PowerVLC relies on technical stacks from the OS & drivers it is running on.
- If you connect your retro stuff on the internet, do not expose any port and always stay behind a NAT router (should be the default in home network configurations). This is the golden rule to take care as it is now common knowledge that XP machines connected to the internet directly are infected in seconds without any user intervention.

## Reporting a Vulnerability
You can contact me by e-mail: olsroparadise@proton.me

Provide me as much details as you can (how to reproduce, in what environment, the impact, etc). I will try to come back to you as fast as I can and update PowerVLC to increase security for all users.
