PowerVLC bundled aMule engine
==============================

PowerVLC includes its own headless `amuled` 3.0.1 engine, built from the pinned
sources below for every shipped architecture. Third-party dependencies are
linked statically; PowerVLC packages never import the official aMule binary or
its dynamic-library closure.

The legacy aMule UPnP client is disabled at build time on every platform: port
mappings are owned by PowerVLC's smaller IGD client. HTTP(S) bootstrap
downloads are likewise delegated to PowerVLC's existing HTTP stack, so the
engine includes neither curl nor a second TLS implementation. aMule's GUI,
web server and command-line clients are not included.
